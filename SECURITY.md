# Security

Found a security problem in Onegram? Please do not open a public issue. Write to [@OnegramSupportBot](https://t.me/OnegramSupportBot) with the word **security** in the first message; we answer there.

Only the latest release is supported. Download builds only from this repository's Releases, [@onegramnews](https://t.me/onegramnews) or [onegram.me](https://onegram.me): copies from other places may be modified.
