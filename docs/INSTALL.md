# Installing Onegram on Android

Onegram runs on any phone with **Android 7.0 or newer**. One universal APK works on every phone.

## 1. Download

- From [GitHub Releases](https://github.com/onegramteam/onegram/releases/latest)
- From [@onegramnews](https://t.me/onegramnews) in Telegram
- From the website: [onegram.me](https://onegram.me)

## 2. Install

1. Open the downloaded APK.
2. If Android asks, allow installing apps from this source (your browser, file manager or Telegram).
3. Tap **Install**.

Onegram has its own package name, so it installs **next to** the official Telegram app. You can keep both.

## 3. Sign in

Enter your phone number. The login code arrives in your Telegram, the same way as on any new device. Your chats, contacts and media load from the Telegram cloud: nothing is lost and nothing has to be moved.

## Updates

- Onegram checks for new versions itself and offers to update right in the app.
- [@onegramnews](https://t.me/onegramnews) gets every new build.
- With [Obtainium](https://github.com/ImranR98/Obtainium): add `https://github.com/onegramteam/onegram` and updates come straight from GitHub Releases.

An update installs over the old version and keeps all your data.

## Troubleshooting

- **"App not installed"**: an APK signed with a different key is already installed under the same name (for example, a build you made yourself). Remove it first, or keep using that one.
- **No notifications**: allow notifications for the app and turn off battery optimisation for it.
- Anything else: write to [@OnegramSupportBot](https://t.me/OnegramSupportBot).
